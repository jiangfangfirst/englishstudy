Key Point 1要点：① be 动词 am/is/are 与主语搭配；② 人称代词主格与形容词性物主代词；③ 姓名（first name / last name）、国籍与班级年级表达；④ 见面问候与自我介绍情景交际。检测
Key Point 2要点：① 实义动词一般现在时（三单变化、do/does 疑问与否定）；② 名词所有格（'s 与 s'）；③ 家庭称谓与代词辨析；④ this/that/these/those 指示代词。检测
Key Point 3要点：① there be 句型（就近原则、否定与疑问）；② 方位介词（next to / across from / in front of / between...and）；③ 校园场所词汇与描述；④ 询问与指路情景交际。检测
Key Point 4要点：① Why...? Because... 原因问答；② 时间介词 at（时刻）/ on（星期与日期）；③ 学科与星期词汇；④ 学科评价形容词（interesting / boring / difficult / useful）。检测
Key Point 5要点：① 情态动词 can/can't 表能力（can + 动词原形）；② play the + 乐器 / play + 球类冠词用法；③ be good at / be interested in 等短语；④ 俱乐部活动情景交际。检测
Key Point 6要点：① 时间表达法（顺读/逆读、a quarter / half past）；② What time / When 特殊疑问句；③ 一般现在时三单与 do/does；④ 频度副词与日常作息短语。检测
Key Point 7要点：① 日期表达法（月份 + 序数词、on + 具体日期）；② 序数词构成（first / second / twelfth）；③ When / How old / How much / How many 特殊疑问句；④ 生日庆祝与购物情景交际。检测
