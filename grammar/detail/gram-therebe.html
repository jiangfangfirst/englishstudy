There be 结构 There be Structure

there be 句型肯定 / 否定 / 疑问 · 就近原则 · there be 和 have 的区别

there be 句型肯定/否定/疑问 就近原则 there be 和 have 区别
01

核心考点概览

考什么 · 怎么考

There be 句型表示「某地 / 某时存在某人或某物」，是初中阶段描述方位、街区、点餐的核心句型，也是中考单项选择、语法填空、句型转换的常客。考查集中在三点：be 动词的单复数由后面的名词决定（就近原则）、否定与疑问的变法、以及 there be 与 have 的汉语都译「有」但不能混用。

there be 句型肯定/否定/疑问
be 动词随主语变化；否定加 not，疑问把 be 提到句首。
就近原则
be 动词与最近的主语保持一致，不管后面还跟多少名词。
there be 和 have 区别
there be 表「存在有」；have 表「拥有」，主语是人。
02

考点逐一精讲

规则 · 公式 · 变形
考点 1

there be 句型肯定/否定/疑问

There be 句型表示「某处有某物」，结构为 There + be + 主语 + 地点 / 时间状语。be 动词的单复数由后面的主语决定，时态可以是 is / are（现在）、was / were（过去）、will be（将来）等。

肯定：There is + 单数名词 / 不可数名词 + 地点状语。　There are + 复数名词 + 地点状语。
否定：be + not（is not / isn't，are not / aren't），some 变 any。
疑问：Be + there + 主语 + ...? 肯定回答 Yes, there is/are. 否定回答 No, there isn't/aren't.
肯定句（单数 / 不可数）
There is a zoo in my neighborhood.（七下 Unit 8）
肯定句（复数）
There are some tomatoes.（七下 Unit 10）
一般疑问句
Is there a post office near here? —Yes, there is.（七下 Unit 8）
复数一般疑问句
Are there any vegetables in the beef noodles?（七下 Unit 10）
否定回答
Is there a hospital on Bridge Street? —No, there isn't.（七下 Unit 8）
否定句中 some 变 any
No, there isn't any meat. / No, there's no meat.（七下 Unit 10）

中考提示：对主语提问用「What's + 地点状语?」，如 What's in the box?（盒子里有什么？），答语用 There is/are...。

考点 2

就近原则

当 there be 后面有两个或多个并列主语时，be 动词的单复数由离它最近的那个主语决定——这就是就近原则。最近的主语是单数 / 不可数，be 用 is（was）；最近的主语是复数，be 用 are（were）。

There is + 单数名词 + and + 复数名词 + ...　就近的单数决定 be 用 is
There are + 复数名词 + and + 单数名词 + ...　就近的复数决定 be 用 are
就近单数 → is
There's also a sweater and a dress.（八下 Unit 10）最近的是 a sweater（单数），用 There's。
同一结构换位 → are
若语序换成复数在前：There are some books and a pen on the desk.（教辅例句）
不可数也算「就近单数」
There is some milk and two eggs in the fridge.（教辅例句）
过去时同样就近
There was a teacher and some students in the classroom.（教辅例句）

口诀：be 动词像门卫，只认离自己最近的人；后面排多长的队，都不影响它的单复数。

考点 3

there be 和 have 区别

汉语里「有」对应两个完全不同的句型：there be 表「存在有」（某地 / 某时有某物），have / has 表「拥有」（主语是人或有生命的主体，强调所属关系）。两者不能在同一个句子里混用。

there be：某地有某物（强调存在，主语在 be 之后）
have / has：某人有某物（强调拥有，主语在前）
存在有 → there be
There is a big park behind the science museum.（八下 Unit 10）博物馆后面「存在」一个公园。
拥有 → have
I've had this bike for three years.（八下 Unit 10）我「拥有」这辆自行车三年了。
「桌上有书」用 there be
There are some books on the desk.（教辅例句）
「我有一本书」用 have
I have a new book.（教辅例句）

快速判断：把句子译成汉语，若能加「在……地方 / 时候」仍通顺，用 there be；若主语是「谁的东西」，用 have。

04

易错点

错在哪 · 怎么改
易错点 1

there be 与 have 混用

错误写法
There has a book on the desk.
正确写法
There is a book on the desk.

解析：there be 句型中只能用 be 动词，不能用 have；表示「存在有」必须用 There is/are。

易错点 2

忽略就近原则

错误写法
There are a pen and two books on the desk.
正确写法
There is a pen and two books on the desk.

解析：离 be 最近的主语是 a pen（单数），按就近原则用 There is；不能看到后面有 two books 就用 are。

易错点 3

疑问句中 some 不变 any

错误写法
Are there some vegetables in the beef noodles?
正确写法
Are there any vegetables in the beef noodles?

解析：一般疑问句中表「一些」要用 any；some 多用于肯定句或表示请求、建议的疑问句。

易错点 4

否定句中 be 后漏 not

错误写法
There isn't some meat in the soup.
正确写法
There isn't any meat in the soup.（= There's no meat in the soup.）

解析：否定句中 some 要变 any；也可以用「no + 名词」直接表否定：There's no meat.。

易错点 5

不可数名词误用 are

错误写法
There are some milk in the glass.
正确写法
There is some milk in the glass.

解析：milk 是不可数名词，作主语时 be 动词用 is，不能用 are。

易错点 6

疑问句语序颠倒

错误写法
There is a post office near here?
正确写法
Is there a post office near here?

解析：there be 的一般疑问句要把 be 动词提到 there 之前：Be + there + 主语 + 状语?

易错点 7

简略回答错用 it

错误写法
—Is there a hospital near here? —Yes, it is.
正确写法
—Is there a hospital near here? —Yes, there is.

解析：there be 句型的简略回答必须保留 there：Yes, there is. / No, there isn't.，不能用 it。

易错点 8

「拥有」错用 there be

错误写法
There is a new bike for me.
正确写法
I have a new bike.

解析：主语「我」拥有一辆自行车，强调所属关系，要用 have；there be 只用于「某地存在某物」。

易错点 9

过去时 be 动词错配

错误写法
There were a zoo near my home ten years ago.
正确写法
There was a zoo near my home ten years ago.

解析：a zoo 是单数，过去时 be 动词用 was；were 只搭配复数主语。

05

关键提醒 · 速记口诀

口诀 · 信号词
there be 句型口诀
there be 句型「某地有」，be 随主语来变化；单数不可数用 is，复数统一都用 are；否定 be 后加 not，some 要变 any 啊；疑问 be 提到 there 前，Yes / No 回答 there 不差。
就近原则口诀
be 动词很「势利」，只看近邻远的不理；近单近不数用 is，近复数才用 are。
there be 与 have 分工
there be 表「存在」，地点状语摆出来；have 表「拥有」，主语必须是「谁」才合拍。
存在有 → there be 拥有 → have / has 某地有 → there be 某人有 → have
常考信号
in my neighborhood（街区） on the desk / wall（桌上/墙上） near here（附近） on Bridge Street（在某街） in the beef noodles（在牛肉面里）

小练习

做完再点开答案
1.There ____ a pen and two books on the desk.
A. isB. areC. have
查看答案
A。就近原则：离 be 最近的主语是 a pen（单数），用 is。
2.—Is there a hospital near here? —____.
A. Yes, it isB. Yes, there isC. No, there is
查看答案
B。there be 句型的简略回答必须保留 there，不能用 it。
3.There ____ some milk and two eggs in the fridge.
A. isB. areC. have
查看答案
A。就近原则：最近的主语 milk 不可数，按单数处理用 is。
4.____ any vegetables in the beef noodles?
A. Is thereB. Are thereC. Have
查看答案
B。主语 vegetables 是复数，疑问句 be 提到 there 前：Are there...?
5.我有一辆新自行车。哪句正确？
A. There is a new bike to me.B. I have a new bike.C. There has a new bike.
查看答案
B。「我拥有一辆自行车」强调所属关系，用 have；there be 与 have 不能混用。
6.There isn't ____ meat in the tomato and egg soup.
A. someB. anyC. a
查看答案
B。否定句中 some 变 any：There isn't any meat = There's no meat.
